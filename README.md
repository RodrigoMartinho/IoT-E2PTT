# IoT-E2PTT
Trabalho da matéria Plataformas de prototipação para IoT

- código em arduinoIDE para dispositivo ESP32 S3, utilizando visor OLED de 2 cores (SSD1306) e sensor Microfone omnidirecional (INMP441).

- criação de um servidor Linux Ubuntu 24.04 no Google Cloud Platform, instalando o Banco de Dados MySQL, o Mosquitto (MQTT) e o NodeRED.

- criação dos fluxos no NodeRED, para comunicação via MQTT e salvar os dados em MySQL, além de criar dashboard para mostrar os dados no navegador.
