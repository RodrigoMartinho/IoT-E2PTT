# IoT-E2PTT
Trabalho da matéria Plataformas de prototipação para IoT

Materiais utilizados:

- ESP32 S3
- Protoboard
- Cabos
- Display OLED 2 cores (SSD1306)
- Microfone omnidirecional (INMP441)
- Led vermelho
- 2 Push button
- Resistor 220 Ohms

Software

 - Servidor Linux 24.04 hospedado no GCP (Google Cloud Platform).
 - Banco de Dados MySQL
 - Mosquitto (MQTT)
 - NodeRED


- criação dos fluxos no NodeRED, para comunicação via MQTT e salvar os dados em MySQL, além de criar dashboard para mostrar os dados no navegador.
